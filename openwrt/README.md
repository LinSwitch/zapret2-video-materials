# Материалы по настройке Zapret2 на OpenWrt

В этой папке собраны конфигурация и списки доменов.

📺 **[Смотреть видео-инструкцию на YouTube](https://youtu.be/yLm1DiBxrLo)**

---

## 🛠 Краткий список команд из видео:

1. **Очистка старых SSH-ключей на ПК (если роутер выдаёт ошибку при подключении):**
   ```bash
   ssh-keygen -R 192.168.1.1
   ```

2. **Подключение к роутеру по SSH:**
   ```bash
   ssh root@192.168.1.1
   ```

3. **Быстрое скачивание и распаковка Запрета прямо на роутере (в папку `/tmp`):**
   ```bash
   cd /tmp
   wget -O zapret.tar.gz https://github.com/bol-van/zapret2/releases/download/v1.0.4/zapret2-v1.0.4-openwrt-embedded.tar.gz
   tar -zxf zapret.tar.gz
   ```
   *(Ссылку на архив замените на актуальную версию)*

4. **Запуск установочного скрипта:**
   ```bash
   cd zapret2-*
   ./install_easy.sh
   ```

5. **Очистка временных файлов после успешной установки:**
   ```bash
   rm -rf /tmp/zap*
   ```

6. **Копирование файлов списков или конфигов с ПК на роутер (SFTP/SCP):**
   Если используете команду `scp` из терминала современных систем, может понадобиться флаг `-O` для совместимости со старыми версиями протокола на роутере:
   ```bash
   scp -O zapret-youtube.txt root@192.168.1.1:/opt/zapret2/ipset/
   ```

7. **Копирование готового конфига прямо на роутер (SCP):**
   ```bash
   scp -O config root@192.168.1.1:/opt/zapret2/
   ```

8. **Редактирование конфигурационного файла (через редактор Vi):**
   ```bash
   vi /opt/zapret2/config
   ```

### 📝 Несколько полезных клавиш для редактора vi:

После открытия файла вы находитесь в **командном режиме**. Чтобы начать что-то делать, используйте эти клавиши:

* **`i`** — переход в режим редактирования (ввода текста).
* **`o`** — вставка новой строки под курсором и переход в режим редактирования.
* **`ESC`** — выход из режима редактирования обратно в командный режим (нажимать обязательно перед вводом команд ниже!).
* **`dd`** — находясь в командном режиме, полностью удаляет строку, на которой стоит курсор.
* **`:wq`** — (команда начинается с двоеточия) сохранить изменения и выйти из редактора.
* **`:q!`** — выйти без сохранения изменений (если что-то случайно пошло не по плану и хотите начать заново).
